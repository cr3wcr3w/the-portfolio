# Introduction to Bash

---

## Basic Commands

- `ls` → List files and directories
- `cd` → Change directory
- `pwd` → Print working directory
- `cp` → Copy files or directories
- `mv` → Move or rename files
- `rm` → Remove files or directories
- `echo` → Print text
- `cat` → Display file contents
- `grep` → Search text patterns
- `cut` → Extract columns from text
- `tr` → Translate or delete characters
- `|` → Pipe output to another command

---

## Bash Script Basics

```bash
#!/bin/bash

echo "Shebang example"

# Make script executable:
# chmod +x script.sh
```

## Variables
```bash
name="John"

echo "$name"
echo "${name}"

# uppercase
echo "${name^^}"

# lowercase
echo "${name,,}"

# substring
echo "${name:0:1}"   # J
echo "${name:0:2}"   # Jo
```

## If Statements
```bash
if [ "$name" = "John" ]; then
    echo "Welcome, John!"
else
    echo "Who are you?"
fi
```

## Loops
```bash
for i in {1..5}; do
    echo "Number: $i"
done
```

## Functions
```bash
greet() {
    echo "Hello $1!"
}

greet "Alice"
```
```bash
greet() {
    echo "Hello $1! You are user number $2."
}

greet "Alice" 1
```

## Arithmetic Operations
```bash
sum=$((5 + 3))
difference=$((5 - 3))
product=$((5 * 3))
quotient=$((5 / 2))
remainder=$((5 % 2))
```

## Ranges and Expansion
```bash
for i in {1..5}; do
    echo "$i"
done
```
```bash
echo 192.168.1.{1..10}
```

## Output Redirection
```bash
ping google.com -c 1 > ip.txt
# > overwrite file
# >> append file
# 2> error output
```

## grep (Search)
```bash
ping google.com -c 1 | grep "64 bytes"
```

## cut (Extract columns)
```bash
cat ip.txt | grep "64 bytes" | cut -d " " -f 5
# -d → delimiter
# -f → field number
```

## tr (Transform text)
```bash
cat ip.txt | grep "64 bytes" | cut -d " " -f 5 | tr -d "():"
```

---
## Simple IP Sweep Script
```bash
#!/bin/bash

for ip in {1..254}; do
    ping -c 1 $1.$ip | grep "64 bytes" | cut -d " " -f 4 | tr -d ":" &
done
```
Make executable:
```bash
chmod +x ipsweep.sh
```
Run:
```bash
./ipsweep.sh 192.168.0
```
## One-liner + scanning example
```bash
./ipsweep.sh 192.168.0 > target.txt
```
```bash
for ip in $(cat target.txt); do
    sudo nmap -sS -p 80 -T4 "$ip" &
done
```

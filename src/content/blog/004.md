Types of Database Relationships

## One-to-One (1:1)
- Each record in Table A is linked to one record in Table B

Example:
A User has one Profile
`Often used for splitting large tables or sensitive data`

## One-to-Many (1:N)
- One record in Table A can be linked to multiple records in Table B
- Most common relationship type

Example:
`One Customer can have many Orders`

## Many-to-Many (M:N)
- Multiple records in Table A can relate to multiple records in Table B 
- Requires a junction table (also called a bridge or associative table)

Example:
Students and Courses

`A student can enroll in many courses, and a course can have many students`

---

## Ownership in Database Relationships
  - When designing relationships, a helpful question to ask is:

`“Who owns whom?”`
(or)
`“Which table depends on the other?”`

This helps you decide where the foreign key should go

Key Idea
  - The owner (parent table) holds the primary key (PK)
  - The dependent (child table) holds the foreign key (FK)
